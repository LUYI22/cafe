# Mallow & Mint Café

A cozy Java Swing café game with an original, pastel animal-neighbor style inspired by the supplied character art. The illustrated shop has four tables, and you can drag waiting customers into open chairs before serving them. Opening the shop starts a day with a random number of guests; serving guests earns sales.

## Run the game

From the project directory, compile and launch with a Java Development Kit installed:

```sh
javac -d bin src/*.java
java -cp bin cafe
```

Choose **Open the shop**, drag each neighbor from the waiting area to an empty chair, and choose **Serve seated guest**. Close the shop when you are ready to end the day.
